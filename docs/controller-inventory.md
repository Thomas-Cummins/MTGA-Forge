# Human controller method inventory

Generated by `python3 tools/controller-inventory.py`. Requires a JDK 17 or newer; no Forge dependencies, protocol schemas, client database, or network access.

PlayerControllerAi declares **125** public/protected instance methods: **45** have exact-signature Arena overrides and **80** remain inherited. Constructors, static methods, and inaccessible internal helpers are excluded.

This is an inventory of source hooks, not a count of bugs. **Choice gap** means source shows a user decision still made automatically if that path is reached; a rig is needed to prove reachability and behavior for each card. **Partial override** means only some cases reach Arena. **Mode-specific choice** means a decision exists in a mechanic or mode that needs a separate support assessment. **Delegates to Arena** and **Alternate route** explain why a missing override is not automatically a bug. **Needs path review** is deliberately unresolved. **Implemented hook** does not mean runtime verified.

Classification notes are manually reviewed in `tools/controller-inventory/review.json`. Each note is tied to a hash of the method and its override; edits mark it **Review stale**. Every newly added method appears automatically. Signature comparison uses Java syntax trees, normalizes qualified type spellings, and preserves parameter types, generics, arrays, and overloads. It does not perform Java type resolution or prove a complete runtime call graph.

Run `python3 tools/controller-inventory.py --check` to detect report drift. Use `--java <path-to-java>` to select a JDK and `--json` for the full extracted methods and source. Run parser/classification regression checks with `python3 tools/controller-inventory/test_inventory.py`.

## Limits and follow-up

- The AI class has internal helpers that cannot be overridden from the Arena package. For example, copied-spell retargeting is handled inside inherited stack-play code; see the partial stack-play override.
- The normal casting path bypasses some inherited hooks. Conversely, an override can still call AI code directly. Inspect the listed superclass calls and the manually noted alternate paths.
- The concrete defaults and final forwarding helpers on PlayerController are not counted as AI hooks. Their source is included in JSON output for further call-path analysis.
- Runtime tracing should record the decision hook, source card, seat, phase, and options, then reproduce a choice different from the AI preference in SelfPlay. Do not dump hidden opponent information.
- The inventory does not cover missing actions or state translation, such as the Fellwar Stone bug. It also does not establish that the client can display every listed mechanic.
